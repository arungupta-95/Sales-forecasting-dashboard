# 📈 Rossmann Sales Forecasting Dashboard

## Live Demo
🚀 [Click here to view dashboard](https://sales-forecasting-dashboard-tfyfhvhig849checwaun4b.streamlit.app)

## Project Overview
End-to-end sales forecasting system built on Rossmann Store Sales dataset 
(1M+ records, 1115 stores). Predicts future sales using Meta's Prophet model.

## Key Results
- ✅ MAPE: 14.75% (Excellent — under 15% industry standard)
- ✅ Forecasts next 2-12 weeks for any store
- ✅ Interactive dashboard with confidence intervals

## Tech Stack
- **Data**: Pandas, NumPy
- **Model**: Facebook Prophet (Time Series)
- **Visualization**: Plotly
- **Dashboard**: Streamlit
- **Deployment**: Streamlit Cloud

## Features
- 📊 Store-wise sales forecasting
- 🎯 Model accuracy metrics (RMSE, MAE, MAPE)
- 📈 Actual vs Predicted visualization
- 🔮 Confidence interval bands
- ⚙️ Adjustable forecast period (2-12 weeks)

## Dataset
Rossmann Store Sales — Kaggle
- 1,017,209 records
- 1,115 stores across Germany
- 2.5 years of daily sales data
